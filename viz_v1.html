HydraGri

HydraGri visualise le bilan hydrique agricole sur une grille spatiale en France : stock d'eau dans le sol, le Gap (déficit hydrique), les précipitations et évapotranspiration potentielle par semaine. Les données sont affichées par maille (plusieurs échelles de résolution). Cliquez sur une maille pour voir la série temporelle.

À propos

HydraGri est développé par notre groupe dans le cadre du projet de visualisation de données. Cette application permet d'explorer les indicateurs du bilan hydrique à l'échelle nationale.
